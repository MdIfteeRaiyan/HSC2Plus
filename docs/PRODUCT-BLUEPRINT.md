# Unnamed HSC Academic Platform — Product Blueprint

## Product promise

This project is the academic command center between TomarShikkha and CampusChoice BD. It guides a Class 11–12 Business Studies or Humanities student through one evidence-based cycle:

**Learn → Practise → Test → Analyse → Revise → Retest**

The home screen always answers one question: **What should I do next to improve my HSC preparation?**

## Product principles inherited from the existing ecosystem

1. Premium simplicity: one primary action per screen, calm surfaces, restrained motion.
2. Explainable guidance: recommendations always state the reason.
3. Mobile parity: no feature may disappear on a small screen.
4. Verified academics: content requires source, syllabus version, reviewer and review date.
5. Useful progress: show topic mastery and next action, not decorative statistics.
6. Human-reviewed automation: AI may assist but never silently publish academic content.
7. Honest status: official, verified, estimated and pending information must remain distinguishable.

## Release sequence

### Foundation — current release

- Working academic dashboard
- Daily Mission interaction
- Subject mastery overview
- Explained MCQ practice
- Smart revision queue concept
- Progress and readiness surfaces
- Desktop sidebar and mobile bottom navigation
- Responsive, accessible visual foundation

### Academic Core

- Supabase accounts and profiles
- Group, subject, paper, chapter and topic hierarchy
- Versioned NCTB syllabus records
- Lessons, quick notes and exam notes
- Reviewed question bank with source metadata
- Persistent attempts, mastery and Mistake Notebook

### Exam Intelligence

- Chapter and multi-chapter tests
- Board-question archive
- CQ rubrics and structured self-evaluation
- Autosave and interrupted-session recovery
- Detailed result analysis
- HSC Readiness Score

### Adaptive Learning

- Spaced revision scheduler
- Diagnostic onboarding
- Dynamic Daily Mission
- Personal study planner
- Weak-topic retest flow
- Guardian weekly summary

### Quality and Scale

- Contributor, reviewer and subject-lead roles
- Draft → review → approve → publish workflow
- Content version history and error reporting
- Source monitoring with human approval
- Performance and product analytics

### Ecosystem Integration

- Shared identity across TomarShikkha, HSC Compass and CampusChoice BD
- Class 10 transition from TomarShikkha
- Post-HSC programme discovery in CampusChoice BD
- Shared preferences and achievements with explicit student consent

## Initial content strategy

Launch depth before breadth. Complete two pilot subjects and two or three chapters in each before expanding. A completed chapter includes concept lessons, quick notes, examples, at least 50 reviewed MCQs, CQs with marking guidance, board-question references, a timed test and revision items.

## North-star metric

The number of students who complete at least one meaningful Learn → Practise → Test → Revise cycle each week.
