# HSC2Plus content-quality audit — 4 November 2026

## Scope

The audit covers the generated notes, chapter lessons, Practice Studio, Test Centre, printable notes and answer support for every subject currently present in Commerce and Humanities.

## Release rules now enforced

- Student-facing question banks start from chapter concept notes, worked examples, formulas, code, graphs, source-based stimuli and solved CQ material.
- Legacy meta-drills such as “best learning method”, “exam sprint”, “mistake clinic”, “full-mark strategy” and generic “which response is best” items are excluded from the visible bank.
- Question minimums are replenished from each chapter's own lessons and material pack; removing filler does not reduce the configured practice capacity.
- English retains paper-specific reading, grammar and writing tasks instead of CQ-shaped group-subject questions.
- Bangla literature retains text evidence, author/work context and complete 1+2+3+4 responses; Bangla Second Paper retains grammar and writing formats.
- ICT questions retain code, output, truth-table, HTML, algorithm and database contexts where the chapter requires them.
- Accounting, Finance, Economics and Statistics use workings, formulas, tables and interpretation rather than prose-only answers.
- Uncited original practice remains labelled Board-pattern. No question is called an authentic previous-board question without board, year, paper, set/code, question number and readable source evidence.

## Language corrections

- Removed deficit-style wording such as “weak chapter” from student progress actions.
- Progress feedback now says that a chapter needs more practice and links directly to the relevant practice flow.
- Student-facing text avoids exposing source-mapping and internal review mechanics before a question.

## Automated safeguards

- Generic note filters remove repeated study-advice paragraphs from printable and online notes.
- Question filters reject non-academic assessment-writing advice disguised as a question.
- Duplicate prompts are detected and differentiated before the final bank is built.
- Every MCQ must contain four options, one answer index and an explanation path.
- Every CQ receives a 1+2+3+4 marking breakdown and a complete model-answer route.

## Human review still required

Automation cannot approve academic truth. A qualified subject reviewer must still sample every chapter for textbook terminology, formulas, dates, calculations, code output, MCQ ambiguity and model-answer depth. Authentic board-paper status also remains evidence-gated.
